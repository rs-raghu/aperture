# Aperture v2 phases

This plan records structural boundaries, not implementation promises. Work beyond an explicitly approved phase remains uncommitted scope.

## Phase 1 — Education domain skeleton: structurally complete

The `@aperture/education` package, its entity shapes, ambient operation declarations, repository and service interfaces, calculation declarations, explicit exports, and inventory documentation are structurally complete. Phase 1 continues to pass the root workspace type-check during Phase 2 verification.

## Phase 2 — Health domain skeleton: structurally complete

The `@aperture/health` package now describes Health, Fitness, Workout, and Running entities; explicit unit values; ambient operation and calculation declarations; repository and service interfaces; explicit public exports; and inventory documentation. Phase 2 adds no executable domain behavior.

## Phase 2 exclusions

Phase 2 excludes UI frameworks and components, server frameworks, APIs, authentication, persistence and migrations, runtime repositories, validation, formulas, diagnosis, health or workout recommendations, training-plan generation, integrations, synchronization, mock or seed data, and behavior tests.

## Phase 3 — not started

Phase 3 has not been authorized or started. Its scope remains undefined until separately approved.

## Implementation status

No implementation phase has started. The completed phases define structural contracts only and make no delivery or technology promises beyond their approved inventories.
