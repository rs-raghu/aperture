# Aperture v2

Aperture v2 is being built incrementally as a new, independent project.

Phase 1 contains only the Education domain structure: TypeScript entity shapes, repository and service interfaces, calculation declarations, package exports, and documentation. Nothing is functional yet. There is no UI, API, authentication, database, runtime repository, validation, or calculation implementation.

Do not enter personal data. The existing Aperture project is retained separately and is not imported into this project.

## Phase 1 commands

```bash
npm install
npm run typecheck
```

See [the phase plan](docs/PHASES.md), [the Education inventory](docs/EDUCATION_SKELETON.md), and [architectural decisions](docs/DECISIONS.md).
